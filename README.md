# Stylus

The contents within are 'borrowed' style sheets I've found off the internet.  Due to the stability of the internet, I wanted to have a place I can obtain the content for the Stylus plugin for Firefox.

I only publish these public so Stylus can get access to them without having to hit other services that sometimes go 'missing', and even with MSoft doing some .. err.. wonderful work(?) with Github as of recent, it's probably more stable than where these styles come from.
